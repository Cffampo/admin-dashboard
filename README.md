# 🌐 Admin Dashboard

A sleek, responsive admin dashboard built with **HTML** and **CSS** as part of [The Odin Project](https://www.theodinproject.com/) curriculum. This project demonstrates my ability to build structured, modern UI layouts using **CSS Grid**, **Flexbox**, and semantic HTML, with a focus on clean design and maintainability.

## 📸 Live Demo

👉 [Check out the live project](https://cffampo.github.io/admin-dashboard/)

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **CSS Grid** – for full-page layout structure
- **Flexbox** – for inner content alignment
- **Google Fonts** – custom typography
- **Responsive Design** – adaptable across screen sizes
- **SVG Icons** – modern, scalable UI assets

---

## 📁 Features

✅ Fully responsive dashboard layout  
✅ Sidebar navigation with scalable icons  
✅ Search bar and profile display in header  
✅ Call-to-action buttons (New, Upload, Share)  
✅ Project card grid with clean spacing  
✅ Announcements and trending section  
✅ Organized, semantic HTML structure  
✅ Built from scratch with no JavaScript

---

## 🧠 What I Learned

- How to structure a full-page layout using **CSS Grid**
- Combining **Flexbox** and **Grid** for clean component design
- Importance of consistent spacing, hierarchy, and alignment
- Working with SVG assets and responsive UI patterns
- Building clean, readable, maintainable code
